# Willy-IA

Pack expérimental Minecraft Bedrock construit à partir du modèle Blockbench fourni.

## Importation
1. Téléchargez `Willy-IA-modele-original.mcaddon`.
2. Ouvrez le fichier avec Minecraft Bedrock.
3. Activez le pack de ressources et le pack de comportements dans les paramètres du monde.
4. Essayez `/summon willy:willy` avec les commandes activées.

## Contenu
- Modèle et texture du robot
- Entité client et contrôleur de rendu
- Animations de repos, marche et salut (le salut n'est pas encore déclenché automatiquement)
- Entité de comportement et manifeste du pack

## Limites connues
Ce pack est une première version et n'a pas encore été testé en jeu. Il ne contient pas de connexion à l'API OpenAI : les réponses conversationnelles IA nécessitent un serveur externe dédié, une clé API gardée côté serveur et une configuration supplémentaire. Ne placez jamais de clé API dans ce dépôt ou dans le fichier `.mcaddon`.
